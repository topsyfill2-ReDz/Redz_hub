# Redz_hub
хаб ввиде бат фаила который позволяет запустить несколько игр через батник есть подсчёт времени в играх и общее время, это моя 1 разработка.

Поддерживаемые игры и программы
1. **OBS Studio**
2. **Deep Rock Galactic**
3. **Garry's Mod**
4. **Counter-Strike 2**
5. **tModLoader**
6. **Forts**
7. **Terraria**
8. **Noclipped** (забейте)
9. **SCP: Secret Laboratory**

Как запустить
1. Скачайте файл `ReDZ_HuB.bat` (нажмите на него в списке файлов выше → кнопка **Download raw file** справа).
2. Запустите скачанный файл двойным кликом.
3. Если появится окно защиты *Windows SmartScreen*, нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. *(Важно)* Не закрывайте окно лаунчера во время игры, если хотите, чтобы время корректно засчиталось в статистику.

можете не волноваться оно без ратки трояна и тд это просто мой первый опыт в кодировании с вспомогательным ии
